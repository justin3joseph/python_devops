# Python for DevOps

A practical GitHub-ready course for students who already know Python basics.

## Course Method
Every module contains:
- `theory.md` — concepts, examples and DevOps context
- `lab.md` — hands-on practical exercises and challenges

## Prerequisites
- Python basics
- Basic Linux commands
- Linux VM, WSL, or lab server
- Git basics
- Docker/AWS for the relevant modules

## Modules
1. Python for DevOps
2. `os`, `sys` and `platform`
3. File and Directory Automation
4. Python + Linux Commands
5. Regular Expressions
6. JSON, YAML and Configuration
7. Command-Line DevOps Tools
8. Python REST API Automation
9. System Monitoring
10. Python + Git
11. Python + Docker
12. Python + AWS
13. Python in CI/CD
14. Python + DevOps Tools
15. Final Project — DevOps Automation Toolkit

## Recommended Duration
Approximately 45–60 hours depending on student experience and lab depth.

## Safety
Use administrative, network, Docker and cloud labs only on systems/accounts where you have authorization. Never commit passwords, API keys, access tokens or private credentials.
