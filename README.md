# Python for DevOps — Instructor Edition

Each module contains:
- `theory.md` — theory
- `lab.md` — student practice labs and challenges
- `solution.md` — instructor solutions

Solutions are provided for the practice/revision exercises in all 15 modules.

**The final challenge in each module is intentionally solution-free.**
Module 15's final project is also solution-free.

Recommended:
- Give students `theory.md` and `lab.md`.
- Keep `solution.md` for the instructor.
