# Lab 08 — Website/API Health Checker

## Objective
Create a Python script that checks whether a URL is reachable.

## Tasks
1. Install `requests`.
2. Accept a URL as a command-line argument.
3. Send a GET request.
4. Use a timeout.
5. Print status code and response time.
6. Return a non-zero status for failure.

## Example
```bash
python api_check.py https://example.com
```

## Challenge
Check three URLs from a text file and create a summary.

## Safety
Only test systems you own or are authorized to monitor.
